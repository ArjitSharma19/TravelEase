# TravelEase 🌍
One-stop travel guide for first-time Indian travellers going abroad.

## Features
- Visa info, currency, SIM, transport & essentials
- AI chat assistant powered by Claude
- Covers 8+ popular destinations

## Tech Stack
HTML | CSS | JavaScript

## Destinations Covered
UAE, USA, UK, Thailand, Singapore, Japan, Canada, Australia

## Setup
1. Clone the repo
2. Add your Anthropic API key in script.js
3. Open index.html in browser
